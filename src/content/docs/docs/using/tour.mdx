## The top bar

<Shot src={strip} alt="The rack with the top bar, an amp block selected and its knobs at the bottom" caption="The top bar, the rack, and the knobs of the selected block." />

From left to right:

- **Preset**: the current scene in amber, the tempo, and the preset name. Tap it to pick
  another preset.
- **DSP / CPU**: the load of the audio processing and of the processor. The dot turns orange,
  then red, as the load gets high. Tap it for the [resource monitor](../../setup/performance/).
- **The pages**: Rack, Presets, Live, Tuner, Looper.
- **⋮**: the menu with the TONE3000 library, Settings, and Power off.

## The pages

| Page | What it is for |
|---|---|
| [Rack](../rack/) | The signal chain: add, move, bypass and tweak blocks |
| [Presets](../presets/) | Save and load presets, build setlists |
| [Live](../live/) | Eight big switches for stomps, scenes or setlist presets, and the tempo |
| [Tuner](../tuner-looper/) | A chromatic tuner, down to 38 Hz |
| [Looper](../tuner-looper/#looper) | Record, overdub, undo |

## Gestures

| Gesture | On a block | Elsewhere |
|---|---|---|
| Tap | Select it: its knobs show at the bottom | Deselect |
| Double tap | Open the full [block editor](../editor/) | |
| Hold and release | Bypass it, or turn it back on | |
| Hold and drag | Move it, also into a split branch | |
| Swipe | | Scroll the rack |

Knobs turn with a vertical drag. Lists open as a full-screen chooser, and text is typed on an
on-screen keyboard.

## Keyboard and encoder

A USB keyboard works: keys `1` to `8` act as the footswitches and `t` taps the tempo. A rotary
encoder wired to the GPIO moves through the controls like the arrow keys and selects with its
push button.
