## Wi-Fi

Tap a network to join it, and type its password on the on-screen keyboard (**#+=** for
symbols). Joined networks are remembered on the data partition; **Forget** removes one. The
password is never shown or logged.

Ethernet needs no setting: plug the cable in.

Set your country in [pedalboard.txt](../pedalboard-txt/) (`wifi_country`) to use the channels
allowed there.

## What is not in Settings

The audio interface, sample rate, buffer and screen rotation are read at boot from
[pedalboard.txt](../pedalboard-txt/), on the card's first partition, so a wrong value can always
be fixed from a computer.
